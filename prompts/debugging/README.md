# Debugging and operations prompts

Diagnose with evidence: hypotheses, stack traces, incidents, root cause, logs and performance.

Each prompt lists the problem it solves, when to use it, the context to prepare, a copy-ready prompt, the output to expect and how to validate that output.

| Prompt | Problem it solves | Skills |
| --- | --- | --- |
| [Hypothesis Driven Debugging](hypothesis-driven-debugging.md) | Trial-and-error fixing hides the root cause. | [debugging-specialist](../../skills/debugging-specialist/SKILL.md) |
| [Stack Trace Analysis](stack-trace-analysis.md) | A stack trace is long and the actual failing frame is not obvious. | [debugging-specialist](../../skills/debugging-specialist/SKILL.md) |
| [Production Incident Analysis](production-incident-analysis.md) | During an incident, teams jump to causes and lose track of facts. | [debugging-specialist](../../skills/debugging-specialist/SKILL.md), [performance-analyst](../../skills/performance-analyst/SKILL.md) |
| [Root Cause Analysis](root-cause-analysis.md) | Post-incident reviews stop at the proximate cause and miss systemic gaps. | [debugging-specialist](../../skills/debugging-specialist/SKILL.md), [regression-analyst](../../skills/regression-analyst/SKILL.md) |
| [Log Analysis](log-analysis.md) | Logs are voluminous and patterns are missed or hallucinated. | [debugging-specialist](../../skills/debugging-specialist/SKILL.md) |
| [Performance Bottleneck Analysis](performance-bottleneck-analysis.md) | Performance work starts with guesses rather than measurements. | [performance-analyst](../../skills/performance-analyst/SKILL.md) |
