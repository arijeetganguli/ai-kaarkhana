# Changelog

All notable changes to this project are recorded here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project intends to use [Semantic Versioning](https://semver.org/) for tagged releases. For a content repository, a *major* change is one that removes or fundamentally changes guidance, *minor* adds material, and *patch* corrects it.

## [Unreleased]

### Added

- **Handbook:** twelve chapters from AI native engineering to engineering leadership, with an index. Chapter 5 includes pages on TDD with AI, test design, and property based and mutation testing; chapter 6 includes a page on why `else` is not always the answer.
- **Skills:** 22 tool agnostic skills in the Agent Skills `SKILL.md` format, a generated [registry](skills/REGISTRY.md) (Markdown and JSON), and a skills guide.
- **Prompts:** 50 prompts in seven categories, each with expected output and validation steps, and a [prompt playground](prompts/playground.md) of weak and strong prompt pairs.
- **Workflows:** ten workflows with Mermaid diagrams, gates and required outputs.
- **Examples:** nine scenarios in Python, Java and TypeScript, each with an initial defect, an improved version and tests; a worked end to end example; and a Broken Code Lab with eight exercises.
- **Templates:** requirement, scenario matrix, technical design, test plan, pull request, code review, AI task, prompt, skill, chapter and ADR templates, and an AI code review checklist.
- **Assets:** original SVG logo, mark, hero image and nine diagrams, generated by `scripts/generate_svgs.py`.
- **Tool adapters:** `AGENTS.md`, `CLAUDE.md`, `.github/copilot-instructions.md`, path specific Copilot instructions, generated `.github/skills` and `.github/prompts`, and an installer for GitHub Copilot, Cursor, Claude Code and generic agents (`scripts/sync_adapters.py`). Conventions were checked against vendor documentation on 2026-11-02.
- **Docs:** getting started, learning paths, maturity assessment, skill of the week, glossary, FAQ and implementation status.
- **Automation:** `scripts/validate_docs.py`, `scripts/build_registry.py`, `scripts/sync_adapters.py` with `--check` modes, `scripts/verify_lab.py`, and GitHub Actions workflows for documentation checks and example tests.
- **Governance:** MIT license, contributing guide, code of conduct, security policy, roadmap, issue forms and a pull request template.
